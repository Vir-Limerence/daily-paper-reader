## 摘要
系统提示是现代人工智能系统中的核心控制机制，塑造着跨对话、任务和用户群体的行为。然而，当反馈仅以聚合指标的形式提供，而非逐示例标签、错误或评论时，它们就难以调整。我们将这种聚合反馈设定研究为样本受限的离散变长文本黑箱优化。我们引入了ReElicit，一个基于启发式嵌入的贝叶斯优化框架。给定任务描述、先前评估的提示以及标量分数，大语言模型会启发式地生成一个紧凑、可解释的特征空间，并将提示映射到其中。借助概率高斯过程代理模型，采集函数接着选择目标特征向量，由大语言模型实现并细化为可部署的系统提示。随着新评估结果到来而重新启发式生成特征空间，使得表示适应观察到的提示-分数历史。我们使用离线基准准确率作为受控的聚合代理来评估该设定：优化器每个提示只观测一个标量分数，没有逐示例标签、错误或评论。在十个系统提示优化任务中，总评估预算为30次，ReElicit在仅使用聚合信息的代表性提示优化基线方法中取得了最强的聚合性能表现。这些结果表明，大语言模型不仅可以作为自然语言工件的贝叶斯优化提示生成器，还能充当自适应语义表示构建者。

## Abstract
System prompts are a central control mechanism in modern AI systems, shaping behavior across conversations, tasks, and user populations. Yet they are difficult to tune when feedback is available only as aggregate metrics rather than per-example labels, failures, or critiques. We study this aggregate feedback setting as sample-constrained black-box optimization over discrete, variable-length text. We introduce ReElicit, a Bayesian optimization framework based on \emph{embedding by elicitation}. Given a task description, previously evaluated prompts, and scalar scores, an LLM elicits a compact, interpretable feature space and maps prompts into it. Leveraging a probabilistic Gaussian process surrogate, an acquisition function then selects target feature vectors, which the LLM realizes and refines into deployable system prompts. Re-eliciting the feature space as new evaluations arrive lets the representation adapt to the observed prompt-score history. We evaluate the setting using offline benchmark accuracy as a controlled aggregate proxy: the optimizer observes one scalar score per prompt and no per-example labels, errors, or critiques. Across ten system prompt optimization tasks with a 30 total evaluation budget, ReElicit achieves the strongest aggregate performance profile among representative aggregate-only prompt-optimization baselines. These results suggest that LLMs can serve as adaptive semantic representation builders, not only prompt generators, for Bayesian optimization over natural-language artifacts.

- **整体含义**：提出 **ReElicit 框架**，通过让 LLM 根据历史评分**动态构建可解释的语义特征空间**，将离散文本搜索转化为连续空间中的贝叶斯优化，从而实现样本高效、可解释且性能优越的系统提示自动优化。

### 2. 论文提出的方法论
- **核心思想（Embedding by Elicitation）**  
  不直接在高维文本空间上搜索，而是利用 LLM 从已有提示-分数历史中**启发式地“引出”一组紧凑的语义特征轴**（例如“推理步骤的显式程度”“对数字一致性的强调”等），并将每个提示映射到这些轴上的 $[0,1]^d$ 坐标。该特征空间作为贝叶斯优化的搜索空间，LLM 再负责将优化器选取的目标向量**实现并细化**为可部署的自然语言提示。

- **关键技术流程（ReElicit 主循环）**  
  1. **特征定义**：LLM 分析当前历史中的高/低分提示模式，生成 $K$ 组候选语义特征描述，并通过交叉验证选出预测分数误差最小的一组。  
  2. **特征提取**：使用选定的特征定义，将历史提示批量映射到数值向量，构建嵌入表。  
  3. **代理建模与采集**：在嵌入空间上拟合高斯过程（GP）代理模型，利用采集函数（qLogNoisyExpectedImprovement）平衡探索与利用，选出下一批 $q$ 个目标特征向量。  
  4. **目标实现与细化**：LLM 根据目标向量先**并行生成多个初始提示**，再**通过特征差距反馈进行顺序细化**，直到向量距离低于阈值或预算耗尽。  
  5. **动态重新启发**：每轮加入新评估数据后，重新执行特征定义与选择，使表示适应新的性能证据。

- **理论支撑（可达性分析）**  
  在以下假设下——真实目标 $f$ 位于一个平滑的“神谕语义嵌入”的再生核希尔伯特空间（RKHS）中，且启发嵌入 $g_t$ 对神谕嵌入 $g^*$ 的逐点误差有界 $\eta_t$——证明了：若在近似函数 $f_t$ 上 $\delta$-次优的提示 $x_t$，其对真实目标的次优性不超过 $\delta + 2BL\eta_t$。这解释了**表示误差 $\eta_t$ 如何主导优化质量**，以及重新启发如何通过降低 $\eta_t$ 来收紧上界。

### 3. 实验设计
- **数据集与场景**  
  10个系统提示优化任务，覆盖数学推理（GSM8K，500题）、多领域知识（MMLU，500题）以及 BIG-Bench Hard 中的 8 个子任务（布尔表达式、歧义消解 QA、对象追踪等，每个 250 题）。  
  优化器仅获取**整个提示在固定评测集上的准确率**，无任何逐样本标签或错误分析。

- **评价协议**  
  总评价预算 $N=30$ 次目标模型调用，分 $T=6$ 批，每批 $q=5$ 个提示。初始批 $D_0$ 由 LLM 一次性生成并评估，后续 5 批为优化轮次。所有方法共享同一组初始数据。每条优化曲线基于 30 个独立随机种子计算均值和 95% 置信区间。

- **对比方法**（均为仅使用聚合标量反馈的自适应版本）  
  - **APE 风格采样**：仅根据任务说明批量生成提示，不使用历史。  
  - **OPRO**：将历史按分数排序后，要求 LLM 生成改进版本。  
  - **PromptBreeder**：基于适应度排序的种群，通过变异（清晰度/推理/简洁）和重组生成后代。  
  - **TextGrad 风格**：先分析评分轨迹、再批判当前最优提示，最后生成多样化改进变体。

- **模型配置**  
  优化器 LLM：Llama 3.3 70B Instruct；目标 LLM：Llama 3.1 8B Instruct。目标模型采用零样本贪心解码输出答案。

### 6. 论文的主要结论与发现
- ReElicit 在所有 10 个任务上**达到最佳或与最佳无统计学差异的成绩**，聚合胜/平率最高（81%）。
- 动态特征空间具有**高重复性（提取噪声低）** 和**适度迭代适应性（CKA 均值 0.81）**，证明重新启发能识别后续轮次中的新语义差异。
- 特征空间在极低样本量下即可**有效拟合 GP 代理**（LEOO-CV MSE 显著低于均值基线），且 BO 目标实现后**与目标向量的差距越小，下一轮改进概率越高**。
- 消融表明，**特征差距细化和 BO 目标选择是两大主要性能贡献因素**；移除细化或替换为随机采样导致显著下降；冻结特征只引起轻微退化（因首次特征已具预测性），而独立提取对性能影响不显著，但可降低调用成本。

### 7. 优点
- **巧妙的表示学习范式**：利用 LLM 的知识直接构建可解释、低维且面向任务的语义坐标，避免了传统稠密嵌入的维数灾难和解码器训练。
- **样本高效**：在极其有限的评价预算（30次）下，实现了对离散文本空间的贝叶斯优化，对实际部署场景极具价值。
- **完整的理论支撑**：给出了表示误差到目标次优性的界限，为动态重新启发提供了理论动机。
- **实验扎实全面**：多任务、多基线、多种子、多消融，且基线适配严格，分析细致（包括代理拟合质量、提取稳定性、目标可达性等）。

### 8. 不足与局限
- **聚合反馈代理的局限性**：实验使用离线基准准确率作为聚合标量，与真实部署中的延迟、人口级指标（如用户满意度）仍有差距，未在真实在线环境中验证。
- **缺乏与更复杂 BO/APO 方法的直接比较**：未适配那些依赖软提示、候选池、固定嵌入或多保真度验证的方法，不能宣称在所有提示优化方法中占优，仅限“仅聚合硬提示”场景。
