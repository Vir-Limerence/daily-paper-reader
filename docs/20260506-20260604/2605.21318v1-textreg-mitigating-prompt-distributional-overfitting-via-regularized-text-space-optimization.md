## 摘要
大型语言模型对用于指定任务目标和行为约束的提示高度敏感。许多最近的提示优化方法使用LLM生成的反馈迭代重写提示，但产生的提示往往变得更长，积累狭隘的样本特定规则，并且在训练分布之外泛化能力差。我们将这种失败模式研究为提示分布过拟合，并认为这反映了离散文本空间优化中缺乏表征控制。我们通过表征低效性来形式化这一观点，这是一种双因素度量，将提示低效性分解为容量成本和范围狭隘性，将分布提示过拟合归因于它们在优化过程中的耦合增长。我们提出TextReg，一个通过正则化文本梯度实现软惩罚目标的正则化框架，结合了双重证据梯度净化、语义编辑正则化和正则化引导的提示更新。在多个推理基准测试中，TextReg显著提高了分布外泛化能力，与TextGrad相比准确率提升高达+11.8%，与REVOLVE相比提升高达+16.5%。

## Abstract
Large language models (LLMs) are highly sensitive to the prompts used to specify task objectives and behavioral constraints. Many recent prompt optimization methods iteratively rewrite prompts using LLM-generated feedback, but the resulting prompts often become longer, accumulate narrow sample-specific rules, and generalize poorly beyond the training distribution. We study this failure mode as prompt distributional overfitting and argue that it reflects a lack of representation control in discrete text-space optimization. We formalize this view through representational inefficiency, a dual-factor measure that decomposes prompt inefficiency into capacity cost and scope narrowness, attributing distributional prompt overfitting to their coupled growth during optimization. We propose TextReg, a regularization framework that realizes a soft-penalty objective through regularized textual gradients, combining Dual-Evidence Gradient Purification, Semantic Edit Regularization, and Regularization-Guided Prompt Update. Across multiple reasoning benchmarks, TextReg substantially improves out-of-distribution (OOD) generalization, with accuracy gains of up to +11.8% over TextGrad and +16.5% over REVOLVE.

*   **核心问题**：**提示分布过拟合**。优化后的提示在训练数据上损失持续降低，但在分布外数据上的泛化性能却急剧下降。
*   **整体含义**：作者将这一问题从表征学习的角度重新定义为**表征低效性**的失败。即，优化过程不受控制地增加了提示的“容量成本”（长度）和“范围狭隘性”（规则的普适性差），二者的耦合增长导致了过拟合。研究旨在通过主动控制这两大因素，产出更短小、更普适、泛化能力更强的提示。

### 论文提出的方法论
论文提出了名为`TextReg`的正则化框架，核心思想是在离散的文本空间中引入“正则化文本梯度”，以软惩罚的方式抑制表征低效性的增长。该方法通过三个核心阶段实现一次完整的正则化提示更新：

1.  **双重证据梯度纯化（Dual-Evidence Gradient Purification）**
    *   **核心思想**：在生成任务梯度（`gtask`）的源头进行过滤，摒弃那些会引入狭隘规则或冗余内容的有害梯度，仅保留能带来普适性提升的梯度（`˜gtask`）。
    *   **技术细节**：
        *   **局部案例证据**：分析当前任务梯度是否追溯至批次中的特定案例（如特定实体、数字），若是，则判定为**案例补丁**，可能增加“范围狭隘性”。
        *   **全局复现证据（RuleBank）**：维护一个跨步骤的规则记忆库`RuleBank`。如果一个规则在优化过程中被频繁接受（高复现频率），则更可能是通用的**广义规则**。
        *   **纯化决策**：一个梯度只有同时满足“非强案例归因”并有“足够的全局复现支持”时，才被保留并重写为简洁、普适的指令；否则被拒绝。

2.  **语义编辑正则化（Semantic Edit Regularization, SER）**
    *   **核心思想**：诊断上一次提示编辑如何改变了表征低效性`I(p)`，并将此变化转化为正则化梯度`greg`，以对抗低效性增长。
    *   **技术细节**：
        *   **有限差分视角**：将提示变化引起的`I(p)`对数变化分解为**容量通道**（`C(p)`，由长度变化衡量）和**范围通道**（`W(p)`，由规则组合的语义变化衡量）。
        *   **通道诊断**：
            *   **容量通道**：当发现提示的相对长度增长超过阈值`τC`时触发。
            *   **范围通道**：通过一个LLM实现的“语义差异分析器”`M∆`比较新旧提示，判断规则的总体范围是变宽了还是**收窄了**。若收窄，则触发。
        *   **梯度合成**：根据触发的通道`A_t`（容量和/或范围），由LLM生成对应的文本引导`greg`，如鼓励压缩、合并或泛化特定规则。

3.  **正则化引导的提示更新（Regularization-Guided Prompt Update）**
    *   **核心思想**：在执行最终提示重写时，以正则化梯度`greg`作为引导信号，在保持任务意图`˜gtask`的同时，选择正则化兼容性最佳的编辑方案。
    *   **技术细节**：
        *   **任务忠实集**：首先根据纯化后的任务梯度`˜gtask`生成一组忠于原任务意图的候选提示。
        *   **引导选择**：在该集合中，选择编辑向量与正则化梯度`greg`冲突最小的候选提示作为最终输出`p_{t+1}`。
        *   **任务主导回退**：当正则化信号与所有任务忠实候选项都不兼容时，算法回退至仅依据任务梯度的更新，确保正则化不扼杀任务性能。
