## 摘要
自动提示优化（APO）在基于大语言模型的智能体工作流中取得了显著提升。然而，现有方法将每个任务的提示视为一个整体、无视实例差异的字符串，通过全局编辑进行优化，导致更新脆弱且无法重用学习到的子行为。我们提出提示码本（PCO），一种新颖的组合式提示优化框架，将APO重新定义为对有限自然语言本能词表的离散学习——这些本能是原子化、可重用的指令单元。PCO将提示构建知识组织在一个离散码本中，并通过基于大语言模型的编码器将每个输入路由到一小部分条目；生成器将它们组合成供冻结目标模型使用的提示；评判器发出结构化裁决，通过归因分解为每个变量的文本梯度，在以语言为值的最小-最大目标下联合训练编码器、生成器和码本。由此得到的路由是每实例化的：同一任务中的不同输入会得到不同的本能组合，这种机制在无视实例的方法下在结构上无法表达。在Qwen3-8B和LLaMA-3.1-8B上的六项基准测试中，PCO相比零样本提升高达+30.36分，在HotpotQA上超过最强先前基线（GEPA）+3.34分，整体上超出+1.11分，且仅使用K=16个本能，部署提示长度相比MIPROv2最多缩短14.1倍，相比GEPA缩短3.0倍。

## Abstract
Automatic prompt optimization (APO) has driven significant gains in LLM-based agentic workflows. However, existing methods treat each task's prompt as a monolithic, instance-blind string optimized through global edits, producing brittle updates and preventing the reuse of learned sub-behaviors. We propose Prompt Codebooks (PCO), a novel compositional prompt optimization framework that recasts APO as discrete learning over a finite vocabulary of natural-language instincts - atomic, reusable instruction units. PCO organizes prompt-construction knowledge in a discrete codebook and routes each input to a small subset of entries via an LLM-based encoder; a generator composes them into a prompt for the frozen target model; a critic emits a structured verdict that decomposes by attribution into per-variable textual gradients, jointly training the encoder, generator, and codebook under a language-valued min-max objective. The resulting routing is per-instance: different inputs in the same task receive different instinct compositions, a regime structurally inexpressible under instance-blind methods. Across six benchmarks on Qwen3-8B and LLaMA-3.1-8B, PCO improves over zero-shot by up to +30.36 points, surpasses the strongest prior baseline (GEPA) by +3.34 on HotpotQA and +1.11 in aggregate, and reduces deployed prompt length by up to 14.1x versus MIPROv2 and 3.0x versus GEPA using only K=16 instincts.

*   **全局纠缠**：为修复某类错误而对提示进行的全局编辑，可能会意外破坏提示在处理其他样本时已优化好的行为，导致更新脆弱且无法复用学习到的子行为。

整体而言，论文主张摒弃传统的整体式提示优化思路，转而采用一种组合式、离散化的方法，将提示构建知识组织为可复用的原子单元，以实现更稳定、高效且可解释的指令精炼。

### 2. 论文提出的方法论（核心思想与关键技术细节）

论文提出的核心方法是**提示码本优化（Prompt Codebooks, PCO）**，其核心思想是将提示优化重构为一个在有限“自然语言本能”词汇表上的离散组合学习过程。PCO框架由四个组件构成：

*   **离散码本**：一个包含 $K$ 个条目（$C = \{c_1, \ldots, c_K\}$）的集合，每个条目是一个简短的、可优化的自然语言指令单元。
*   **提示编码器**：实现为一个具有可训练系统提示 $\theta$ 的大语言模型。它根据输入 $x$ 动态选择 $S$ 个码本条目的索引（$S \ll K$），实现了**每实例自适应路由**。
*   **提示生成器**：实现为一个具有可训练系统提示 $\phi$ 的大语言模型。它将编码器选中的 $S$ 个本能组合、压缩成最终发送给目标模型的流畅提示。
*   **评判器**：基于固定大语言模型的对手，它接收模型响应、输入、提示和参考答案，输出一个结构化的自然语言“裁决”（$\ell_{\text{text}}$），指出是生成的哪部分或哪个环节导致了失败。

**关键技术流程与公式**：

1.  **目标函数**：PCO训练一个语言值的最小-最大化目标：
    $$ \Theta^* = \underset{\theta, \phi, C}{\arg\max}\ \underset{\psi}{\min}\ \mathbb{E}_{(x, y^*)} \left[ r(M(p, x), y^*) - \rho(D_\psi(y, x, p, y^*)) \right] $$
    其中 $r$ 是任务奖励，$\rho$ 是评判器裁决的标量惩罚。外部优化器（编码器、生成器、码本）最大化奖励并最小化惩罚，内部对手为固定评判器。

2.  **文本梯度归因与更新**：评判器发出的自然语言裁决 $\ell_{\text{text}}$ 被一个基于大语言模型的归因算子分解为指向各个组件的文本梯度：
    *   $g_\phi$（生成器忠实度）：惩罚生成器未能准确地将选中的本能渲染成提示。
    *   $g_{c_k}$（本能质量）：针对选中的每个码本条目，评判其是否有用、有害或模糊，并进行局部重写。
    *   $g_\theta$（路由质量）：评判编码器是否为当前输入选择了正确的本能。
    组件的元提示利用其对应的文本梯度 $g_v$ 进行原地更新，实现了仅针对失败环节的**局部化信用分配**。

3.  **优化算法**：为防止码本崩溃（Encoder只选择少数条目），采用**$\epsilon$-贪心路由**与**成功率加权采样**。以 $1-\epsilon$ 的概率使用编码器路由，以 $\epsilon$ 的概率根据条目的历史成功率进行加权随机采样。$\epsilon$ 从1.0衰减至0.15，以确保初期探索、后期利用。

*   **新颖的范式转换**：首次将提示优化建模为对“自然语言本能”库的离散组合选择问题，为领域提供了新视角。

### 8. 不足与局限（包括实验覆盖、偏差风险、应用限制等）

*   **计算开销较大**：与基于启发式搜索的方法相比，PCO的训练过程需要大量的评判、归因和更新调用（如一次运行约24,000次调用），文本梯度优化的计算开销高于简单搜索。
*   **超参数敏感性**：码本大小（$K$）和瓶颈宽度（$S$）对性能有显著影响。过大的$K$会稀释优化信号，过宽的$S$会引入噪声，这增加了超参数调优的成本。
*   **组合抽象的权衡**：虽然离散路由提升了组合推理和指令复用，但激进的压缩可能会降低对格式精确度要求极高的任务上的性能。例如，在HoVer任务上PCO弱于GEPA+Merge。
*   **缺乏跨任务迁移验证**：论文主要集中在为单个任务学习独立的码本，并未探索已学习的本能跨任务迁移的潜力。
*   **未使用前沿闭源模型**：实验固于资源，仅在8B规模的开源模型上进行，未与GPT-4等可能表现更强的前沿闭源模型进行对比。
